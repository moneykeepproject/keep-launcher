MoneyKeep Launcher portable mode

While this file sits next to keep-launcher.exe, MoneyKeep Launcher keeps its settings, its
download cache and its record of installed apps in the MoneyKeepLauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move MoneyKeep Launcher with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\MoneyKeep Launcher) instead.
If MoneyKeepLauncherData can't be written (for example on a read-only drive), MoneyKeep Launcher says
so and uses %APPDATA%\MoneyKeep Launcher instead.
