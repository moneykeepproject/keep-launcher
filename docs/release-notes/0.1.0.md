# MoneyKeep Launcher 0.1.0

MoneyKeep Launcher is one place to install, update and open the MoneyKeep Apps:
MoneyKeep (personal and small-business accounting), CalcKeep (financial calculators),
GroupKeep (dividing group expenses) and Form1099Keep (Forms 1099-NEC and 1099-MISC).
It picks the right download for your computer, checks it before installing, and tells
you when an update is out.

This is the first public release, and it is early software: please read
[Known limits](../known-limits.md).

## What's in 0.1.0

- A list of every MoneyKeep App, showing which ones you have and which version, as a
  grid of cards or a sortable table.
- **Install** picks the build for your system and processor, checks it against the
  release's `SHA256SUMS.txt` and installs it where your system normally keeps
  applications. It also finds apps you installed yourself.
- **Updates:** the launcher checks each app's releases and updates the ones you have,
  in the same format you installed them with. A notification tells you when something
  new is out. An app that is running is never replaced.
- **Open** any MoneyKeep App from the window, or from the menu-bar or system-tray icon.
- The launcher keeps itself up to date with **Update and restart**.
- 13 interface languages; **Auto** follows your system's language, and Settings →
  Language picks one.
- A web version that shows the same list in a browser, with the latest download for
  each app.

## Install

### Windows (10 and 11)

Download `keep-launcher-0.1.0-windows-x64.msi` from the release (or the `arm64` file
for Windows on Arm, or `x86` for 32-bit Windows) and run it. It installs for your
account only, so it needs no administrator permission. If you'd rather not install
anything, the `-portable.zip` files run from any folder.

Installing a MoneyKeep App from the launcher asks for administrator permission, since
the apps install for everyone on the computer.

### Mac (macOS 11 or later, Apple silicon and Intel)

Download `keep-launcher-0.1.0-macos-universal.dmg`, open it and drag MoneyKeep
Launcher to Applications.

This Mac build is not yet signed with an Apple Developer ID, so macOS warns the first
time you open it. Right-click (or Control-click) MoneyKeep Launcher in Applications,
then choose **Open**, and confirm. If macOS doesn't offer **Open**, go to System
Settings > Privacy & Security, scroll down and choose **Open Anyway** next to MoneyKeep
Launcher. You only need to do this once.

On a Mac, the launcher can't install the MoneyKeep Apps yet (see
[Known limits](../known-limits.md)): install each app from its own release, and the
launcher finds it, opens it and links you to new versions.

### Linux, FreeBSD and the web version

The release also has AppImage, `.deb`, `.rpm`, Flatpak and plain `.tar.gz` builds for
Linux, a FreeBSD build and the web version. The [README](../../README.md#downloads)
says which file to choose.

## Checking your download

Each release has a file called `SHA256SUMS.txt`. It lists a fingerprint (a SHA-256
checksum) for every file in the release. The launcher checks every app it installs
against it. To check the launcher's own download:

- **Windows:** open PowerShell in the folder with the file and run
  `Get-FileHash .\keep-launcher-0.1.0-windows-x64.msi -Algorithm SHA256`
- **Mac:** open Terminal in the folder with the file and run
  `shasum -a 256 keep-launcher-0.1.0-macos-universal.dmg`
- **Linux or FreeBSD:** run `sha256sum <file>` (Linux) or `sha256 <file>` (FreeBSD).

Compare the long string it prints with the one next to the file's name in
`SHA256SUMS.txt` (capital and small letters count as the same). If they differ, don't
open the file: download it again.
