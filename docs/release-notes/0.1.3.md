# MoneyKeep Launcher 0.1.3

MoneyKeep Launcher 0.1.3 adds ShareKeep to the MoneyKeep Apps it installs and keeps up
to date. It includes everything in [0.1.2](0.1.2.md) (the launcher's own update, and
the Mac folder window). For everything the launcher does, see the [0.1.0 release
notes](0.1.0.md) and the [0.1.1 notes](0.1.1.md) (the Mac build), and please read
[Known limits](../known-limits.md).

## What's new in 0.1.3

- **ShareKeep is in the list.** ShareKeep keeps a household's shared money: rent,
  bills and groceries split the way the household agrees, from everyone's phone or
  computer, with one computer at home as the hub. The launcher shows it with the other
  MoneyKeep Apps, with its own page, and installs, opens and updates it like the rest.
- **The launcher updates itself** (from 0.1.2). 0.1.0 and 0.1.1 offered their update,
  then failed with an error that named another product's launcher. From 0.1.2 on, the
  launcher updates itself from its own releases on Windows (the installer and the
  portable zip) and Linux (AppImage, `.deb`, `.rpm`, Flatpak and `.tar.gz`). On a Mac,
  and on FreeBSD, it links to the new version instead.
- **Install 0.1.3 by hand once if you have 0.1.0 or 0.1.1.** Those versions can't
  install an update themselves: download 0.1.3 below and install it over the old one.
  Your settings and the apps you installed stay as they are.
- **Mac: Browse… no longer closes the launcher** (from 0.1.2). The folder window
  slides down from the top of the launcher's window; choose **Cancel** to close it.
- The Windows installer and update are still unsigned. An update is checked against
  the release's published SHA-256 fingerprint before it's installed, as every app
  install is.

## Install

### Windows (10 and 11)

Download `keep-launcher-0.1.3-windows-x64.msi` from the release (or the `arm64` file
for Windows on Arm, or `x86` for 32-bit Windows) and run it. It installs for your
account only, so it needs no administrator permission. If you'd rather not install
anything, the `-portable.zip` files run from any folder.

Installing a MoneyKeep App from the launcher asks for administrator permission, since
the apps install for everyone on the computer.

### Mac (macOS 11 or later, Apple silicon and Intel)

Download `keep-launcher-0.1.3-macos-universal.dmg`, open it and drag MoneyKeep
Launcher to Applications.

This Mac build is not yet signed with an Apple Developer ID, so macOS warns the first
time you open it. Right-click (or Control-click) MoneyKeep Launcher in Applications,
then choose **Open**, and confirm. If macOS doesn't offer **Open**, go to System
Settings > Privacy & Security, scroll down and choose **Open Anyway** next to MoneyKeep
Launcher. You only need to do this once.

On a Mac, the launcher can't install the MoneyKeep Apps yet (see
[Known limits](../known-limits.md)): install each app from its own release, and the
launcher finds it, opens it and links you to new versions.

### Linux, FreeBSD and the web version

The release also has AppImage, `.deb`, `.rpm`, Flatpak and plain `.tar.gz` builds for
Linux, a FreeBSD build and the web version. The [README](../../README.md#downloads)
says which file to choose.

## Checking your download

Each release has a file called `SHA256SUMS.txt`. It lists a fingerprint (a SHA-256
checksum) for every file in the release. The launcher checks every app it installs
against it. To check the launcher's own download:

- **Windows:** open PowerShell in the folder with the file and run
  `Get-FileHash .\keep-launcher-0.1.3-windows-x64.msi -Algorithm SHA256`
- **Mac:** open Terminal in the folder with the file and run
  `shasum -a 256 keep-launcher-0.1.3-macos-universal.dmg`
- **Linux or FreeBSD:** run `sha256sum <file>` (Linux) or `sha256 <file>` (FreeBSD).

Compare the long string it prints with the one next to the file's name in
`SHA256SUMS.txt` (capital and small letters count as the same). If they differ, don't
open the file: download it again.
